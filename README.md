# パチンコ・パチスロ収支帳 - 競馬もまとめて収支管理 v1.0

スマホ向けPWA版です。

## 搭載機能
- パチンコ / パチスロ / 競馬の収支記録
- 日付、店舗・競馬場、機種・レース名、投資額、回収額、メモ
- 収支自動計算
- 月別 / 年別 / 累計
- 総投資、総回収、回収率、勝率
- 累計収支グラフ
- 履歴の検索・編集・削除
- 店舗・競馬場別成績
- 月別成績
- JSONバックアップ / 復元
- PWA対応

## 公開
GitHub Pages等のHTTPS環境に index.html 以下一式をアップロードしてください。
iPhoneではSafariで公開URLを開き、「共有」→「ホーム画面に追加」でアプリ風に利用できます。

※記録データはブラウザのlocalStorageに保存されます。端末変更・ブラウザデータ削除に備えて設定画面から定期的にバックアップしてください。
